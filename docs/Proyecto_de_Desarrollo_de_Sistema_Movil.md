# Desarrollo de Sistemas Móviles


# Introducción

Los grupos de alumnos deberán desarrollar un sistema móvil con las herramientas que se enseñarán en el curso. El proyecto tiene la finalidad de preparar a los alumnos al desarrollo practico de soluciones móviles.

- **Objetivo.** Análisis y desarrollo de sistema móvil.
- **Herramientas.** Android Studio.
- **Lenguaje de programación.** Kotlin.
- **Herramientas complementarias.** Copilot y/o Gemini.
- **Tiempo de desarrollo.** El tiempo de desarrollo del curso.
- **Control de avances.** La clase de cada semana.
- **Grupo de alumnos.** Formación de 4 alumnos por grupo, cada grupo debe tener un nombre a Alias, este alias se usará en el proceso de la comunicación con el profesor.
- **Metodología.** El grupo debe elegir la metodología de desarrollo y gestión del proyecto.
- **Herramientas de análisis.** UML para el modelamiento del sistema.
- **Herramienta de análisis de datos.** Debe contener el modelo Entidad-relación si es un motor de datos relacional, o la documentación de entidades JSON si no es relacional.
- **Requerimientos mínimos del sistema.** El sistema debe capturar datos, procesarlos, consultarlos y almacenarlos en repositorios persistentes, tal como SQLite.
- **Nivel de complejidad.** El grupo debe seleccionar el proyecto con libertad de elección, pero considerando la aprobación del profesor, es para delimitar la solución del problema.

---

# Estructura del proyecto

1. **Objetivos del proyecto.** Indica la solución que implementara el sistema.

2. **Requerimientos funcionales.** Conjunto de requerimientos de procesos a resolver.

3. **Requerimientos no funcionales.** Especificaciones del proyecto y del producto.

   Considerar que los requerimientos no funcionales contienen restricciones de la aplicación móvil, requisitos de la aplicación, lenguajes de programación, especificaciones del dispositivo sobre el cual se instalara.

4. **Modelo conceptual.** Grafica que indique la distribución de los procesos de sistema de cara al usuario.

5. **Aplicar UML u otra herramienta de análisis de procesos**, que contenga el diagrama de las actividades del sistema, diagramas de clases, diagrama de estado si lo requiera.

6. **Utilizar alguna herramienta** que el grupo considere para el modelamiento de datos.

7. **Determinar el proceso de desarrollo** en el tiempo declarado, puede ser mediante gráfica GANTT.

8. **Establecer la distribución de la carga** de cada alumno del grupo en el desarrollo del sistema móvil.
