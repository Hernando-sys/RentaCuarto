# Seguridad y datos personales

RentaCuarto es un proyecto académico local. Puede almacenar nombres, DNI y teléfonos de inquilinos; **no publiques registros reales** ni copias de las bases SQLite.

- No incluyas archivos `.db`, `.sqlite`, `.jks`, `.keystore`, `local.properties` ni claves API en commits.
- En capturas, informes y issues utiliza datos ficticios; difumina DNI o teléfonos reales.
- Los datos de muestra solo se generan en variantes `debug` y no deben contener información real.
- No se declara cifrado de base, copia de seguridad externa, cuentas ni autorización multiusuario como funciones ya implementadas.
- Antes de usar la aplicación con datos productivos debe completarse la política de respaldo, privacidad, protección del dispositivo y pruebas de integridad.

Si encuentras un problema sensible, comunícalo privadamente con el responsable del repositorio en lugar de publicar datos de terceros en un issue.
